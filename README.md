# 🎵 پخش کننده موسیقی ساده (MP3 Player)

## توضیحات
یک پخش کننده موسیقی سبک و کاربرپسند که با پایتون و کتابخانه Tkinter ساخته شده است. این برنامه امکان پخش فایل‌های MP3 از پوشه‌های محلی را فراهم می‌کند.

## امکانات
- پخش فایل‌های MP3
- امکان توقف و ادامه پخش
- متوقف کردن کامل پخش
- باز کردن پوشه‌های حاوی موسیقی و بارگذاری خودکار فایل‌ها
- پاک کردن لیست پخش
- رابط کاربری ساده و قابل فهم

## نیازمندی‌ها
- پایتون نسخه 3.x
- کتابخانه Pygame
- کتابخانه Tkinter (معمولا همراه پایتون نصب می‌شود)

## نحوه نصب
1. دانلود فایل main.py
2. نصب کتابخانه‌های مورد نیاز:
   ```bash
   pip install pygame
   ```

## راهنمای استفاده
1. اجرای برنامه:
   ```bash
   python main.py
   ```
2. استفاده از منوها و دکمه‌ها برای:
   - باز کردن پوشه حاوی فایل‌های MP3
   - پخش، توقف، ادامه یا قطع پخش موسیقی
   - پاک کردن لیست فعلی

## راهنمای رابط کاربری
- **دکمه‌ها:**
  - پخش آهنگ انتخاب شده
  - توقف موقت آهنگ جاری
  - ادامه آهنگ متوقف شده
  - توقف کامل پخش
- **منوها:**
  - فایل → باز کردن پوشه، پاک کردن لیست، خروج
  - راهنما → مشاهده راهنما، درباره برنامه
